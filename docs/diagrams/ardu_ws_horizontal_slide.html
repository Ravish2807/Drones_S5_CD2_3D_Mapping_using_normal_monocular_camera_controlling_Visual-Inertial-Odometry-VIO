🟠 MODEL 1 · ERROR-STATE EKF + GEOMETRIC SO(3) (model1_so3_controller.py) 50 Hz Real-Time
1. Error-State EKF
12-State δx = [δp, δv, δθ, δω]T
Manifold: R ← R • Exp(δθ)
Joseph: (I-KH)P(I-KH)T + KRKT
Sensor noise & bias rejection
2. Outer Position Loop
Runs on estimator state: p̂, v̂
ep = pd - p̂ • ev = vd - v̂
ad = p̈d + Kpep + Kvev
3. Attitude Generator
Fd = m(ad - g)
b3d = Fd / ||Fd|| • Rd ∈ SO(3)
Collective thrust: T = Fd • (R e3)
4. SO(3) Geometric
eR = ½(RdTR - RTRd)∨
τ = -KReR - KΩeω + ω×Jω
Singularity-free >90° tilt
