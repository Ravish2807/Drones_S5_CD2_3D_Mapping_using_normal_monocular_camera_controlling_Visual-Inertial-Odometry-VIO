4 THREE CONTROLLER MODELS (Core Flight Engine)
0 - SO(3) CASCADED CONTROLLER (baseline) controller_node (50 Hz)
• Position controller (outer loop):
  ep = pd - p, ev = vd - v | ad = p̈d + Kp ep + Kv ev
  Velocity clamp: v_cmd = clamp(Kp ep + Kv ev, vmax=1.0 m/s)
• Attitude generator:
  Fd = m(ad - g) ➔ Thrust axis: b3d = Fd / ||Fd|| ➔ Rd = [b1d, b2d, b3d] ∈ SO(3)
• SO(3) geometric controller (inner loop):
  eR = ½(Rdᵀ R - Rᵀ Rd)ᵛ, eω = ω - Rᵀ Rd ωd | τ = -KR eR - KΩ eω
• Output: Publishes velocity command in map / base_link frame
MODEL 1 - ERROR-STATE EKF + GEOMETRIC SO(3) model1_so3_controller (50 Hz)
• Error-State EKF (Block 4):
  12-State error: δx = [δp, δv, δθ, δω]ᵀ ∈ ℝ¹² with Lie manifold addition R ← R·Exp(δθ)
  Rodrigues Exp/Log roundtrip machine precision: 6.3×10⁻¹⁷
  Discretization: F = I + A·Δt, Covariance propagation: P = F P Fᵀ + Q·Δt
  Joseph-form covariance update: P ← (I - KH)P(I - KH)ᵀ + KRnKᵀ
• Position controller (outer loop) - on estimator:
  ep = pd - p_hat, ev = vd - v_hat | ad = p̈d + Kp ep + Kv ev
• Attitude generator: Fd = m(ad - g) ➔ b3d = Fd / ||Fd|| ➔ Rd ∈ SO(3)
  Body thrust projection: T = Fd · (R e3)
• SO(3) geometric controller: τ = -KR eR - KΩ eω + ω × Jω (>90° tilt tolerance)
• Output: Publishes /ap/v1/cmd_vel, controller_type = MODEL_1_SO3_GEOMETRIC
MODEL 2 - DMDC SYSTEM ID + LQR / MPC model2_dmdc_controller (25 Hz)
• State deviation (Block 1):
  xk = [pk - pref; vk; Log(Rk); ωk] ∈ ℝ¹², uk = [Tk - mg0; τk] ∈ ℝ⁴ (mg0 = 14.715 N)
• DMDc system identification (Block 2):
  Online snapshot regression: [A B] = X⁺ [X; U]† over rolling flight buffers
  Blended with analytical hover linearization prior (Aphys, Bphys) for t=0 stability
• control_mode? Decision (lqr | mpc):
  [LQR Mode]: DARE Riccati: P = AᵀPA - AᵀPB(R + BᵀPB)⁻¹BᵀPA + Q ➔ u = -K xk
  [MPC Mode]: Stacked QP over horizon N=25 (1.0s, dt=0.04s), Pf = PDARE
    Hard box constraints: 5N ≤ T ≤ 25N, |τ| ≤ 0.5 N·m (solve: 0.42 ms)
• Actuation synthesis (Block 10 - output): uk = utrim + u0* ➔ maps to body cmd_vel
  Publishes controller_type = MODEL_2_DMDC_MPC or LQR
