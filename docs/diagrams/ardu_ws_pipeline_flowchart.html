3. Core Flight Controller Engine (3 Models)

Master Launcher: ros2 launch drones_controller controller.launch.py model:=0|1|2 mode:=mpc|lqr
🔹 MODEL 0: Baseline Cascaded SO(3) Controller controller_node (50 Hz)
• Outer Loop: Position error ep = pd - p, Velocity error ev = vd - v
  Virtual commanded acceleration: ad = p̈d + Kp ep + Kv ev
• Attitude Generator: Desired force Fd = m(ad - g) ➔ Thrust axis b3d = Fd / ||Fd||
  Computes orthonormal desired rotation matrix Rd = [b1d, b2d, b3d] ∈ SO(3)
• Inner Loop: Attitude error eR = ½(Rdᵀ R - Rᵀ Rd)ᵛ, Rate error eω
  Control torque output: τ = -KR eR - KΩ eω
🟣 MODEL 1: Nonlinear Model-Based & Geometric SO(3) model1_so3_controller (50 Hz)
• 12-State Error-State EKF (Block 4):
  Propagates error state δx = [δp, δv, δθ, δω]ᵀ ∈ ℝ¹² on Lie group manifold
  State injection via Rodrigues Exponential: R ← R · Exp(δθ) (error: 6.3×10⁻¹⁷)
  Joseph-form covariance stabilization: P ← (I - KH)P(I - KH)ᵀ + KRnKᵀ
• Outer-Loop Guidance (Blocks 5 & 6):
  Desired force Fd = m(ad - g) ➔ Body thrust projection: T = Fd · (R e3)
• Geometric SO(3) Attitude Tracking (Block 7):
  Singularity-free large-angle flight (>90° tilt capability):
  τ = -KR eR - KΩ eω + ω × Jω
🟢 MODEL 2: Data-Driven DMDc & Optimal Control (LQR / MPC) model2_dmdc_controller (25 Hz)
• DMDc System Identification (Blocks 1 & 2):
  Online regression [A B] = X⁺ [X; U]† over rolling snapshot flight buffers
  Blended with analytical hover linearization prior (Aphys, Bphys) for t=0 stability
• LQR Branch (Blocks 3–6):
  Solves DARE Riccati recursion: P = AᵀPA - AᵀPB(R + BᵀPB)⁻¹BᵀPA + Q
  Feedback gain K = (R + BᵀPB)⁻¹BᵀPA ∈ ℝ⁴ˣ¹² ➔ u = -K xk
• Constrained QP MPC Branch (Blocks 7–9):
  Stacked QP over horizon N = 25 (1.0s, dt=0.04s) with terminal cost Pf = PDARE
  Actuator box constraints: 5N ≤ T ≤ 25N, |τ| ≤ 0.5 N·m (solve: 0.42 ms)
• Actuation: uk = utrim + u0* (Receding horizon dispatch)
